# 0004 — Cloudflare service mapping for LobeHub's non-portable infrastructure

## Context

Research (see `research/01-lobehub-architecture.md` and `research/03-exotic-subsystems-feasibility.md`) found several pieces of LobeHub's infrastructure that don't translate directly to the target stack (D1/SQLite instead of Postgres, no external job queue). Confirmed via the `cloudflare` and `agents-sdk` skills (Cloudflare docs, fetched live during planning) that Cloudflare has legitimate first-party equivalents for all of them except the cloud sandbox, which needs a genuine reimplementation rather than a port.

## Decision

| ------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| ParadeDB `pg_search` (BM25 full-text, e.g. on agents/topics/files/knowledge_bases)                                                    | D1 FTS5 virtual tables                                                                                                                                                                                       | Not yet verified for search-quality parity — flagged as an open risk in MIGRATION_PLAN.md, confirm when the relevant phase starts.                                                                                                                                                                                                                                                                                                                                  |

| LobeHub Market SDK-backed sandbox (default) / proprietary "OnlyBoxes" API (alternate)                                                 | Cloudflare Sandbox SDK (`@cloudflare/sandbox`: Container + Durable Object)                                                                                                                                   | **Not a port** — neither upstream option is self-hostable (Market SDK depends on the excluded marketplace backend; OnlyBoxes is an undocumented LobeHub-proprietary paid API with no public docs or self-host path). This is a from-scratch reimplementation of the same _user-facing_ capability (agent code execution) on Cloudflare's own infrastructure. Containers is in beta (no SLA) as of this research — acceptable for now, noted as an operational risk. |
